# Attribution

This repository (sparks-crosswalk) contains build artifacts generated from
[sparks-crosswalk-data](https://github.com/statsvine/sparks-crosswalk-data), which aggregates
identifiers from multiple open and community-driven public sources.

The authoritative attribution for those sources is maintained alongside the data itself, in
[sparks-crosswalk-data/ATTRIBUTION.md](https://github.com/statsvine/sparks-crosswalk-data/blob/main/ATTRIBUTION.md).
In summary, the identifiers here derive from Wikidata, IPTC Media Topics, the ESPN core API,
Reuters sports slugs, and the MLB StatsAPI.

## General notes

- Wherever possible, contributions to this project aim to respect original licenses and terms of use.
- This project does not redistribute raw source data in bulk, only normalized cross-reference mappings.
- If you maintain one of the upstream sources and want its attribution corrected or its identifiers
  removed, please open an issue on
  [sparks-crosswalk-data](https://github.com/statsvine/sparks-crosswalk-data).
